# VHBD görüntü alt kümesi

Bu klasördeki altı görüntü, **Visual Hydraulics Lab Blockage Dataset (VHBD)** içinden arayüz akışı için seçilmiştir.

- Kaynak: *Computer Vision Datasets for Visual Blockage Assessment at Culverts*
- Yazarlar: Umair Iqbal, Johan Barthelemy, Pascal Perez, Tim Davies, Benoit Passot
- DOI: <https://doi.org/10.5281/zenodo.7623641>
- Lisans: [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/)
- Bağlam: Kontrollü hidrolik laboratuvarında kaydedilmiş menfez görüntüleri

Dosyalar yeniden adlandırılmıştır. Kaynaktaki dosya adları ve sınıf etiketleri `vision_samples.json` içinde korunur.
